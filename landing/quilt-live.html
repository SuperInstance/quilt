        ◳ Welcome to Quilt Live

        A portable, reactive data OS — in one HTML file. You own the data.

        1. Click a cell to inspect it

        The right panel shows its dependencies, dependents, and raw value. Click any id to jump there.

        2. Press s on a value cell to set it

        Or e to edit a formula. The grid reactively recomputes everything that depends on it.

        3. Press + to add a new cell

        Pick a kind (value, formula, program…) and give it an id and body. It joins the live graph instantly.

        4. Save your work

        Save stores it in a browser cookie (auto-loads next time). Download gives you a single .html with the state baked in — you can email it, commit it, or run it offline forever.
