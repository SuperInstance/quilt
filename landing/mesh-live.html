The mesh is the network

Open this page in two browser tabs and watch cells sync peer-to-peer. No server, no internet, no account. CRDT + Lamport clocks + gossip. Just like quilt-mesh, but live in your browser.

How to test

  1. Click the button below to enable mesh sync on this tab. You'll get a peer ID like peer-2-abc123.
  2. Open this same page in a second tab, window, or browser.
  3. Edit a cell in one tab — it appears in the other. Try changing values simultaneously to see the CRDT resolve conflicts.
  4. Disconnect your internet. The cells still work locally. Reconnect — they sync.
