What's in the box

The primitives no one else combines.

Each is real. Each is in the engine today. Together they're the new shape of composable systems.

◇

Cell-as-capability

A cell can be a value, a formula, an API call, a model, a sensor, an actuator, a listener, or a router. Changing A1 reroutes every dependent automatically.

⇄

Caller-aware routing

Every call carries caller.row, caller.column, caller.identity. A cell routes on who called it. Row 10+ uses Model A. Column J uses Prompt X.

◉

Reactive, by default

Pure formulas recalculate on dep change. Sensors push. Listeners fire. The graph is alive. No polling, no manual orchestration.

⇌

MCP-native

Every named cell is an MCP tool. Every sheet is an MCP server. Claude Code, Cursor, and any MCP client can use your cells as tools and shared memory.

⊕

Edge-ready

Runs on a Raspberry Pi. Sensors in, actuators out, local model on a Pi, all in the same sheet. No cloud round-trip for control loops.

∞

Classical ↔ jazz

Mix deterministic algorithms with stochastic models in the same grid. See exactly where the jazz is. Decompose over time — visible, auditable, editable.

◳

Human + agent shared space

The agent writes a cell; you see it instantly. You override a cell; the agent reads it on the next cycle. Same grid, same view, same audit log.

⌘

Git-friendly YAML

Sheets are .quilt.yaml files. Diffable, mergeable, reviewable. LLMs can write them. Humans can read them. No binary blobs.

⊟

Terminal-native

TUI for tmux. Watch agents work. Step in. Override. The terminal is the power tool — Quilt lives there.

In code

Look how small it is.

A boat autopilot with sensors, PID control, voice commands, and a model router. One YAML file. About 100 lines.

boat-autopilot.cellflow.yaml
CLI
MCP
# A reactive control system. The grid is the runtime.
id: boat-autopilot
title: "Voice-Controlled Autopilot"

cells:
  # --- Sensors (push from hardware) ---
  - id: compass.heading
    kind: sensor
    source: nmea:/dev/ttyUSB0
    unit: degrees

  # --- Pure computations (reactive) ---
  - id: heading.error
    kind: formula
    expr: "=((desired.heading - compass.heading + 540) % 360) - 180"

  # --- Program cells (stateful, async) ---
  - id: rudder.command
    kind: program
    code: |
      const e = await runtime.get('heading.error');
      const g = await runtime.get('rudder.gain');
      return clamp((e.data || 0) * (g.data || 0.5), -30, 30);

  # --- Router (caller-aware) ---
  - id: model.router
    kind: router
    rules:
      - when: 'caller.row === "boat-1"'
        route: { model: "gpt-4o-mini" }
      - when: 'caller.row === "boat-2"'
        route: { model: "gpt-4o" }

  # --- Actuators (write to hardware) ---
  - id: rudder.position
    kind: io
    direction: out
    port: actuator:rudder

And then you just quilt run boat-autopilot.cellflow.yaml — or quilt serve --mcp to expose it to Claude Code.

Get started

Five minutes to your first cell.

1

Install

npm install -g @quilt/cli

Requires Node.js 18+. The CLI brings the runtime, the MCP server, and the TUI.

2

Scaffold

quilt init my-sheet

Creates a starter sheet with two cells — a value and a formula.

3

Run

quilt run my-sheet.quilt.yaml

Watch the cells evaluate. Edit the YAML, re-run, watch them change.

4

Expose to MCP

quilt serve my-sheet.quilt.yaml --mcp

Now Claude Code (or any MCP client) can use your cells as tools.
