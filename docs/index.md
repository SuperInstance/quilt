features:
  - title: 9 cell kinds
    details: value, formula, api, program, sensor, listener, router, io, ai. Compose any combination. Cells wire together with reactive propagation.
  - title: 5 deployment tiers
    details: Browser, server, compiled binary, edge (Cloudflare/ESP32/Jetson), codespace. The same engine runs everywhere.
  - title: Federated by URI
    details: quilt://instance/sheet#cell. Subscribe to any cell on any tier. ESP32 → codespace → server with one line of code.
  - title: TypeScript + Rust
    details: The TS engine for browsers and agents. The Rust engine for binaries, embedded, and edge. Same sheet format.
  - title: AI-native
    details: Cells can be LLM calls. The `ai` cell kind is a first-class evaluator. Per-context memoization. Content-addressed cache.
  - title: Save your work
    details: Every cell is addressable, every sheet is portable, every state is replayable. Quilt-Live is a 70KB browser file.
