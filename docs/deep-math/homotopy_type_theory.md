**Preface: The Quilt Axiom**

The conservation law γ + η = 1 is stated as a *type invariant*—not a runtime check, but a structural precondition for the cell's very existence. In standard programming, a type is a set of values. In Quilt, a type is a *space*, and the invariant is a *path* within that space.

HoTT gives us the precise language for this. In HoTT, the identity type `Id_A(a, b)` is not a boolean proposition ("are a and b equal?") but a *space of paths* from `a` to `b` in the type `A`. The fundamental insight is that *equality is a structure*, not a property. Quilt’s γ and η are not two independent properties; they are the two endpoints of a fundamental path. The invariant γ+η=1 is the *type* of that path.

We will construct this model rigorously. We will define the Quilt cell as a dependent type `Cell : QuiltType → Type`, where `QuiltType` is the universe of the 8 primitive types. We will show that the triple `(γ, η, p)` where `p : γ + η = 1` forms a *higher inductive type* (HIT), specifically a cylinder or interval. We will then map the 8 primitives to type constructors, and the 8 operation primitives to transport functions along these paths.

### 1. The Base Space: The Quilt Universe

First, we need a universe. Let `𝒬` be the universe of Quilt types. Unlike the standard `Type`, `𝒬` is a *directed* universe with a built-in metric.

**Definition 1.1 (The Quilt Universe).** The universe `𝒬` is a category with:
- **Objects:** The 8 primitives: `Num`, `Str`, `Bool`, `Arr`, `Obj`, `Fml`, `CellRef`, `SheetRef`.
- **Morphisms:** All *valid type transformations* between these, generated by the 8 operations (Z_in, Z_out, JEPA, DoubleEntry, Vibe, GC, Murmur, Graph).
- **A monoidal structure:** `Tensor` (for spatial composition) and `Par` (for temporal composition).

**Definition 1.2 (Cell as a Dependent Type).** A Quilt cell is not an element of a type; it is a *type family*. Specifically, for any primitive types `A, B ∈ 𝒬`, a cell `C` is defined as:

```
C : A × B → Type
```

where `A` is the *input envelope* and `B` is the *output envelope*. The cell itself is a *witness* of the transformation `A → B`.

**Crucially**, every such cell `C` carries a canonical element:
```
γ : C(a, b)
η : C(a, b)
```
But `γ` and `η` are not arbitrary elements. They are *destructors* of a higher-order structure.

### 2. The Interval Type and the Conservation Law

We introduce the central object: the *Quilt Interval*.

**Definition 2.1 (The Quilt Interval).** Let `I` be the interval type defined as a higher inductive type with:
- **Constructors:**
  - `zero : I`
  - `one : I`
- **Path constructor:**
  - `seg : zero = one` (in the identity type `Id_I(zero, one)`)

This is the standard interval in HoTT. Now, we assert the **Fundamental Quilt Axiom (FQA)**:

```
FQA : I → Type
FQA(i) := Σ(γ : ℝ) (η : ℝ), (γ + η = 1) ∧ (i = zero → γ = 1, η = 0) ∧ (i = one → γ = 0, η = 1)
```

In simpler terms: the interval `I` is *fibered* over pairs `(γ, η)`. The point `zero` maps to the pair `(1, 0)`. The point `one` maps to `(0, 1)`. But the *path* `seg` maps to a *path* in the space of pairs, which is exactly the line `γ + η = 1`.

**Property 2.2 (γ+η=1 as a Type, not a Proposition).** In HoTT, we cannot write `γ + η = 1` as a mere proposition. We must write it as a *type*: `Id_ℝ(γ + η, 1)`. This is the space of all proofs that `γ + η` equals `1`. Because `ℝ` is a set (in HoTT, a 0-type), this identity type is a proposition. However, its *fiber* over the interval `I` is non-trivial.

We model the entire cell as the *dependent pair*:
```
QuiltCell(A, B) := Σ(γ : ℝ) (η : ℝ), (γ + η = 1) × (A → B)
```
But this is not enough. We need the *path* structure. So we define:

**Definition 2.3 (The Cell as a Fibration).** A Quilt cell `C` is a *fibration* `E → I` where:
- The fiber over `zero` is the type of *pure input* states (γ=1, η=0).
- The fiber over `one` is the type of *pure output* states (γ=0, η=1).
- The fibration itself (the total space `E`) is the type of all *computational states*.

**The conservation law is the path-lifting property.** For any element `e_0` in the fiber over `zero`, and any path `p : I → E` such that `proj(p) = seg`, the endpoint `e_1` in the fiber over `one` satisfies the equation `γ(e_1) + η(e_1) = 1`. This is not a theorem we prove; it is the *definition* of what it means for `E` to be a fibration over `I`.

### 3. The 8 Primitives as Paths and Type Constructors

Now we map the 8 primitives to specific type-theoretic operations. These are not functions on data; they are *path induction* principles, *transport* functions, and *higher inductive* constructors.

**3.1 Z_in and Z_out (The Zero State and One State).**
- `Z_in` is the *left unit* of the interval. It is the constructor `zero : I`. In the cell's type, `Z_in` is the *canonical equality* `refl : γ + η = 1` evaluated at `γ=1`.
- `Z_out` is the *right unit*. It is `one : I`.

These are not operations that set a flag. They are the *endpoints* of the interval. `Z_in` is the *type* `CellType` with `γ=1`. `Z_out` is the *type* `CellType` with `η=1`. The law `γ+η=1` is the *path* connecting them.

**3.2 JEPA (Joint Embedding Predictive Architecture).**
JEPA is the *path constructor* `seg : zero = one`. In type theory, JEPA is the *generator* of the identity type. It takes as input the left fiber (input space) and produces the right fiber (output space) via a *path*.

Concretely, JEPA is the *transport* function:
```
transport^JEPA : (γ + η = 1) → (P(zero) → P(one))
```
where `P` is a type family. In Quilt terms, JEPA is the *predictive* jump. It takes the input `x` and produces a *predicted output* `ŷ` such that the *cost function* (the distance between `ŷ` and the actual output) is exactly the *curvature* of the path `seg`. The conservation law ensures that the *total energy* (γ + η) is constant along this transport.

**3.3 DoubleEntry (DE).**
DoubleEntry is the *equality reflection*. In type theory, this is the *univalence axiom* restricted to Quilt types. DE states that if two cells are *equivalent* (i.e., there is a homotopy between their fibrations), then they are *equal*.

```
DE : (A ≃ B) → (A = B)
```
In Quilt, this is the accounting identity. Every transaction in cell `A` must have a corresponding opposite entry in cell `B`. This is not a rule about numbers; it is the *identity type* `Id_𝒬(A, B)`. DE is the constructor of that identity type.

Technically, DE is the *path* between the two fibers. If cell `A` has `γ=0.7, η=0.3` and cell `B` has `γ=0.3, η=0.7`, then DE provides the *proof* that `A = B` in the universe `𝒬`, because they are mirror images along the line `γ + η = 1`. The *sum* of the two cells' γ values equals 1, and the sum of their η values equals 1. This is the type-theoretic version of *balance*.

**3.4 Vibe (The Modal Operator).**
Vibe is the *truncation* operator. In HoTT, we have `‖A‖_n`, the n-truncation of a type. Vibe is the *propositional truncation* `‖A‖_{-1}` applied to the *computational context*. It collapses all higher path information (the "noise", the *computational complexity*) into a mere proposition: "the computation is valid".

Vibe is the *isProp* constructor. It takes a cell `C` and returns a proof that *all* paths in `C` are equal. In Quilt terms, Vibe is the *judgment* of sameness. It is what tells us that two different implementations of the same logical cell have the same *type*.

Type-theoretically, Vibe is the map:
```
Vibe : (C : CellType) → isContr(‖C‖)
```
This ensures that the *semantic value* of a cell (its γ and η) is independent of the *computational path* taken, as long as γ+η=1. Vibe is the *ensuring* that the interval `I` is *connected*.

**3.5 GC (Garbage Collection).**
GC is the *path elimination* or *torsor* operation. In HoTT, we have the *path induction* principle (J). GC is the *J* rule for the Quilt interval.

```
GC : (P : (x : I) → Type) → (P(zero)) → (P(one)) → (path between them) → (x : I) → P(x)
```

In Quilt, GC is the *garbage collector*. It terminates a cell's computation. It does this by providing the *endpoint* `one` (i.e., η=1). When GC runs, it forces the path `seg` to collapse to the point `one`. This is the *elimination rule* for the interval.

But more subtly, GC is the *identity elimination*. If we have a cell with `γ=0.5, η=0.5`, GC does not destroy it. It *normalizes* the path. It replaces the non-trivial path `seg` with the reflexivity path `refl` at the point `one`. This is the *canonical* garbage collection: it reduces the computation to its *normal form*, which is the point where η=1.

**3.6 Murmur (Hash and Noise).**
Murmur is the *higher path* constructor. In HoTT, we have *higher inductive types* that generate not just paths, but paths between paths (2-paths), etc. Murmur is the *suspension* or *spherical* generator.

Specifically, Murmur takes the interval `I` and creates a *loop* on top of it. It generates a new path:
```
murmur : (p : γ + η = 1) → (p = p)
```
This is a *2-path* that represents the "noise" or "hash" inherent in the computation. It does not change the conservation law; it just decorates the path with a *symmetry*.

In Quilt terms, Murmur is the *entropy* generator. It creates a unique identifier for the cell (a hash) by leveraging the *higher dimensional* structure of the interval. The hash is not a random number; it is a *homotopy* between the two proofs of `γ+η=1`. Because there are infinitely many such 2-paths (if the interval is not truncated), Murmur can generate infinite uniqueness.

**3.7 Graph (Structure of Relations).**
Graph is the *join* operation in type theory. For types `A` and `B`, the join `A * B` is a higher inductive type with two constructors `inl : A → A*B` and `inr : B → A*B`, and a path constructor ensuring that *all* points in `A` and `B` are connected.

In Quilt, Graph is the *spatial tensor* of two cells. If we have `CellA` with `γ1+η1=1` and `CellB` with `γ2+η2=1`, then Graph creates a new cell where the interval `I` is replaced by the *square* `I × I`. The conservation law becomes:
```
(γ1 + γ2) + (η1 + η2) = 2
```
which is automatically satisfied by the product structure. Graph is the *product type* `A × B` lifted to the *path space*.

### 4. The DoubleEntry as a Special Case of HoTT Univalence

Let's delve deeper into DoubleEntry. In standard HoTT, univalence says:
```
(A = B) ≃ (A ≃ B)
```
For Quilt, we restrict this to the *metric* determined by γ and η. Define a *Quilt-equivalence* `A ≃_Q B` as a pair of maps `f : A → B` and `g : B → A` such that:
```
γ(f(a)) = η(a)  and  η(f(a)) = γ(a)
```
and similarly for `g`. This is a *duality* transformation.

**Theorem (DoubleEntry as Univalence).** The DoubleEntry primitive is the *univalence axiom* for the Quilt universe `𝒬`. It states:
```
DE : (A ≃_Q B) → (A =_Q B)
```

**Proof Sketch.** The path space `Id_𝒬(A, B)` is the set of all homotopies between the fibrations. Since the fibrations are determined by γ and η, a homotopy is a function that maps the point `zero` to `one` or vice versa. The map `DE` takes such a homotopy and returns the *identity* in the universe. This is exactly the transport along the interval `I` that swaps γ and η. ∎

This is why DoubleEntry is so powerful in accounting: it states that *balance* is the same as *equality*. A balanced ledger (where γ=η=0.5) is *equal* to a reversed ledger (where γ=1, η=0). They are the same object in the homotopy type.

### 5. Cell as a Type in Martin-Löf Type Theory (MLTT)

We now answer the core question: **Can the Quilt cell be modeled as a type in MLTT?** Yes, but with a twist.

In vanilla MLTT, we have dependent types `A : Type`. We cannot express the interval `I` with the path constructor `seg` without extending MLTT to *Homotopy* MLTT (HoTT). However, we can model the *invariant* in MLTT using *propositional equality*.

**Definition 5.1 (MLTT Encoding).** In MLTT, we define a cell as a record:
```
Cell : Type
Cell := { γ : ℝ ; η : ℝ ; law : γ + η = 1 }
```
Here, `law` is a *proof* of equality. In MLTT, this is a *term* of type `Id_ℝ(γ + η, 1)`. This is a valid type. The problem is that MLTT's equality is *extensional* (in Extensional Type Theory, ETT) or *intensional* (ITT). In ETT, `law` is a proposition. In ITT, it is a *term*.

**The failing of MLTT:** In MLTT, there is no way to say that the *space* of all `law` proofs is connected. You cannot have a non-constant function from the interval to the type of proofs. The *conservation law* becomes a mere *constraint*, not a *generator* of paths.

**The HoTT leap:** We must replace the *propositional equality* `γ + η = 1` with the *path type* `Id_ℝ(γ + η, 1)`. But to make this a *path*, we need to *rewrite* `γ` and `η` as *dependent on an interval*.

**Definition 5.2 (The Correct Model).** We define a *Quilt cell* as a type family:
```
Cell : I → Type
Cell(i) := (γ : ℝ) × (η : ℝ) × (γ + η = 1) × (H(i))
```
where `H(i)` is a proposition that says:
- If `i = zero`, then `γ = 1`.
- If `i = one`, then `η = 1`.
- If `i = seg` (the path), then `γ` and `η` vary linearly.

This is a *dependent type over the interval*. The *total space* `Σ(i : I), Cell(i)` is the *full state space* of the cell. This is a 1-dimensional bundle over the interval. The *conservation law* is the *fiberwise* condition.

### 6. The Primitive Operations in This Model

Given `Cell(i)` as above, the 8 primitives become:

1.  **Z_in:** `zero : I` and the fiber `Cell(zero)`.
2.  **Z_out:** `one : I` and the fiber `Cell(one)`.
3.  **JEPA:** The *path* `seg : zero = one` and the *transport* `transport^seg : Cell(zero) → Cell(one)`. This is the *predictive* function.
4.  **DoubleEntry:** The *univalence* equivalence between `Cell(zero)` and `Cell(one)`, showing they are the same type.
5.  **Vibe:** The *proof* that `Cell(i)` is a *proposition* (i.e., all paths in it are equal) for a fixed `i`. This is the *modal collapse*.
6.  **GC:** The *path elimination* rule. Given `P : (i : I) → Cell(i) → Type`, GC allows you to prove `P(i, c)` for all `i` by proving it for `zero` and `one`. This is the *J* rule.
7.  **Murmur:** The generator of a *2-path* in the fiber. It produces `murmer : (c : Cell(i)) → (c = c)`, a non-trivial auto-homotopy, encoding the hash.
8.  **Graph:** The *dependent pair* type `Σ(i : I), Cell(i)` for multiple cells, forming a *simplicial set* of intervals.

### 7. The Homotopy Theory of Quilt

We can now state two theorems:

**Theorem 7.1 (The Contractibility of Computational State).** For any cell with a *fixed* γ and η satisfying γ+η=1, the type of all *computational paths* that result in that state is *contractible* (up to the Murmur 2-path). This is the type-theoretic version of *determinism*: given the invariants, the computation is unique.

**Proof Sketch.** Let `c₀` be a state. Any other state `c₁` with the same γ,η is connected to `c₀` by a path in the fiber. The interval `I` is contractible (since it's an interval). Therefore, the total space of all paths is contractible. The only non-trivial homotopy is the Murmur loop. ∎

**Theorem 7.2 (The Topological Invariance of Quilt).** The conservation law γ+η=1 is a *homotopy invariant*. It is preserved under all 8 primitives, because each primitive is a *continuous map* on the interval `I`.

**Proof Sketch.** Every primitive is a *type constructor* or *transport function*. Transport preserves path structure. The sum `γ+η` is a continuous function on `ℝ`. The preimage of `1` is a line. Every primitive maps this line to itself (Z_in, Z_out) or maps it to another line via a homotopy (DoubleEntry swaps it). Therefore, the law is invariant under the complete group of transformations generated by the 8 primitives. This group is homotopy equivalent to the group of homeomorphisms of the interval. ∎
